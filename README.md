## Ожидание, глубокий сон и пробуждение

- Через 5 минут без нажатий `CONFIG_ZMK_IDLE_TIMEOUT=300000` переводит клавиатуру в обычное состояние ожидания. Глубокий сон при этом не включается.
- `CONFIG_ZMK_SLEEP=y` и `CONFIG_ZMK_IDLE_SLEEP_TIMEOUT=54000000` задают глубокий сон примерно через 15 часов без активности, в том числе если компьютер или телефон отключён. Время считается с последней активности, а не с момента потери Bluetooth. Питание по USB обычно препятствует глубокому сну на подключённой половинке.
- Левая половинка — центральная, правая — периферийная. У каждой свой таймер активности: действия на левой не обязательно продлевают работу неиспользуемой правой половинки. Если она уснула, нажмите клавишу на ней; если уснули обе, разбудите каждую. После пробуждения подождите восстановления связи; первое нажатие может не попасть на компьютер.
- `wakeup-source` в общей конфигурации матрицы включает пробуждение клавишей для обеих половинок. Реальную работу на конкретном устройстве нужно проверить после прошивки. До проверки сохраняйте доступ к физической кнопке Reset: одиночное нажатие перезапускает контроллер; оно не должно стирать Bluetooth-сопряжения. Нажатие Reset два раза обычно запускает загрузчик для прошивки, а прошивка `settings_reset` удаляет сохранённые настройки и сопряжения.
- До глубокого сна связь или попытки переподключения могут потреблять больше энергии. По одной ёмкости батареи нельзя надёжно рассчитать время работы: нужно измерить ток обеих половинок в подключённом и отключённом состояниях. Подсветка в `config/dac_man_5x6.conf` отключена, но другие аппаратные потребители могут оставаться включёнными.

### Сборка и проверка

1. Загрузите изменения в репозиторий и дождитесь успешной сборки GitHub Actions. Скачайте артефакт прошивки для этой сборки. Репозиторий использует ветку ZMK `main`, поэтому будущие сборки могут отличаться.
2. Подключите левую половинку по USB, дважды нажмите Reset для входа в загрузчик и скопируйте файл `dac_man_5x6_left` с расширением `.uf2` на появившийся накопитель. Аналогично прошейте правую половинку файлом `dac_man_5x6_right`. Не используйте файл `settings_reset` для обычного обновления.
3. Проверьте обе половинки, подключение к устройству и восстановление связи после отключения Bluetooth. Для проверки глубокого сна можно временно поставить одинаковый короткий таймер в обоих `.conf` файлах, собрать и прошить обе половинки, затем проверить пробуждение каждой клавишей. После теста обязательно верните `54000000`, заново соберите и прошейте обе половинки.

Подробнее: [Low Power States](https://zmk.dev/docs/features/low-power-states), [Flashing the Firmware](https://zmk.dev/docs/user-setup#flashing-the-firmware), [Split Keyboards](https://zmk.dev/docs/features/split-keyboards).
